# SPK Risiko Diabetes - Tema Biru

Aplikasi berbasis Python dan Streamlit untuk studi kasus klasifikasi risiko diabetes menggunakan KNN.

## File untuk GitHub
- `app.py`: kode utama aplikasi.
- `requirements.txt`: daftar library yang dibutuhkan.

## Cara deploy
1. Buat repository GitHub.
2. Upload `app.py` dan `requirements.txt` ke bagian utama (root) repository.
3. Buka https://share.streamlit.io dan masuk dengan akun GitHub.
4. Buat aplikasi baru, pilih repository dan branch, lalu pilih `app.py` sebagai main file.
5. Klik Deploy. Setelah proses selesai, bagikan link Streamlit yang muncul.

Aplikasi memuat 10 data latihan dari studi kasus akademik, input data pasien, pilihan K = 1/3/5, hasil klasifikasi, serta tabel tetangga terdekat dan dataset latihan.

Catatan: data bersifat studi kasus dan hasilnya bukan diagnosis medis.
